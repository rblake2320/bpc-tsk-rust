# Keyforge control-plane screenshots

These screenshots document the companion **Keyforge** privileged control-plane interface. They are captured from the live local preview and contain no authenticated user identity, BPC pair ID, TSK client ID, raw secret, backup, authority DSN, certificate, or configuration value.

- `keyforge-access-gate.png` — the completed unauthenticated operator gate.
- `keyforge-how-to-use.png` — the public operator workflow guide.
- `keyforge-security-assurance.png` — the public assurance language, including the prohibition on “uncrackable” and unsupported crack-time marketing claims.

They are documentation only. The `v0.1.0-production` tag remains the released request-admission service source; these images are later non-executable documentation on `main`.
